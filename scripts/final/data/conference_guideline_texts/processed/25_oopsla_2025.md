1. **Availability**: Artifact must be stored in a permanent archival location with a DOI; GitHub or institutional URLs alone are not sufficient.
2. **Functionality**: Artifact is documented, consistent, complete, exercisable, and includes verification/validation evidence.
3. **Reusability**: Artifact meets Functional requirements and is carefully documented, well-structured, and organized to facilitate reuse.
4. **Results Validation**: Artifact can reproduce the main scientific claims of the paper (“Results Reproduced” badge).
5. **Completeness**: Artifact must support the claims in the paper per its Data-Availability Statement; missing essential components (e.g., benchmarks) without substitutes leads to rejection.
6. **Documentation**: Clear instructions for setup, usage, and reproduction; expected runtime and hardware limitations must be documented.
7. **Hardware/Environment Requirements**: If specialized hardware is required (e.g., large RAM, GPUs), arrangements must be made with AEC chairs in advance, potentially via cloud access. 
8. **Version Updates**: Authors may publish fixed versions after reviewer feedback for the Available badge.
9. **Evaluation Scope**: Paper proofs generally not evaluated for Functional or Reusable badges, but may still qualify for Available.
10. **Submission Verification**: Available badge only granted if artifact is submitted to AEC for verification, even if already public.
